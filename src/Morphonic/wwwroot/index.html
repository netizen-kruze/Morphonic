Settings

Recommended defaults
Sets the block size and context to the best choice for this machine, 50 ms crossfade, loudness following on, and automatic acceleration. Your devices and voice are untouched.
Block size
How much audio each conversion pass handles. Smaller = less delay but more passes per second; if the pace chip turns red, go up.
Context
Speech before each block the encoder also sees. More context is more natural and costs CPU time per pass.
Crossfade
Overlap between consecutive blocks. Longer hides seams better and adds a little delay.
Noise gate
Frames quieter than this are silenced before conversion, so room noise never becomes a voice.
Loudness follows you
How much the converted voice follows your own loudness. Fully: whispers stay whispers. Off: the voice keeps its trained loudness.
Output gain
Makes the converted voice louder or quieter.
Speaker
Voices trained with several speakers expose them by number; almost every voice has only speaker 0.
Monitor
Also play the converted voice to a second output — your headphones — so you hear what others hear.
Acceleration
Auto uses GPU acceleration when it is installed and this machine can run it; CPU forces the processor. Applies after a restart.
Virtual microphone
Creates "Morphonic-Voice-Mic", an input other programs can pick, and plays the voice into it. Needs PipeWire (pipewire-pulse). Applies after a restart.

Speed check

How fast is conversion on this PC?
Converts a bundled 14-second clip with the chosen voice, block by block as the live loop does, and rates the result. Takes under a minute; the voice must be stopped. The result is also written to bench.log for bug reports.

Conversion

Converting .pth voices
Standard RVC v2 voices convert inside the app. A checkpoint with an unusual configuration falls back to the bundled Python tool, which needs Python 3 with PyTorch.

Desktop

Add to app grid
Copies Morphonic to ~/.local/share/Morphonic/app and adds it to your app grid. No root needed.
